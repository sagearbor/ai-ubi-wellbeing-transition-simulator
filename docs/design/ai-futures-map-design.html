AI Futures Map

One graph: time left to right, goodness of the world up and down, probability mass flowing through it like a river. Non-exclusive branches feed it, interventions bend it, a pasted bill becomes a wedge on it, and the model earns trust by hindcasting the last decade. Three community weight tiers: locked, invited experts, public.

0. Recommendation in one card

  • The one graph. X is time 2026 to 2045. Y is goodness of the world, 0 to 100, on the same scale as the simulator's wellbeing index. Five exclusive world-states sit at fixed heights (flourishing 90, muddling 60, stratified 40, recoverable catastrophe 20, existential 0). Each state is a ribbon whose thickness is its probability. Ribbons peel apart from today's single point, the way a fan chart widens. A mean line runs through the middle. This is a Sankey drawn on a goodness axis, and because the states are exclusive the flow is genuinely conserved.
  • Feeding it. Roughly 20 non-exclusive event nodes ("AGI exists", "mass unemployment without a safety net", "oligarchic capture", "misaligned takeover"), each with a likelihood curve by year, connected by signed edges in log-odds, one number each. Edges run from events into the world-states. Exclusivity is enforced in exactly one place, the world-state axis.
  • Interventions are wedges. An intervention is a named bundle of nudges on nodes plus a cost band. Its effect on the one graph is measured four ways: mean shift, floor lift (bad tail shrinks), ceiling lift (good tail grows), and cost. Wedges stack like the climate stabilisation wedges; a cost curve ranks them like the climate abatement curve.
  • Paste a bill. Text or URL goes to Gemini, which fills an intervention card by picking from the fixed node list and a coarse magnitude enum, with a quoted sentence per pick. A human reviews, then the graph animates from baseline to the new shape. The model never types a free number.
  • Hindcast. The country simulator starts from real 2015 data and is scored against actual wellbeing (World Happiness Report ladder) and GDP through 2025. Scores are anchor tests. The futures map earns trust the slow way: every estimate is dated and scored as events resolve.
  • Votes are on node likelihoods and state marginals only. The graph propagates what-ifs; it never derives the baseline. Pool in log-odds, median for public, trimmed mean for experts, one-year half-life, shrink toward the seed when thin, always show n and the band.
  • Storage. Locked tier is JSON in git, ajv-validated like the existing model configs. Expert and public votes go to Firestore on the GCP project already in use. No API server, no Cloud Functions.
  • Not a re-creation of Anthropic's explorer. Theirs asks for model inputs and shows 2030 US outputs with no probabilities and no history. This asks for beliefs about outcomes, attaches probabilities, goes global and past 2030, scores against reality, and prices interventions. Section 13.

    2. Why non-exclusive branches work

    A flowchart where branches split into exclusive alternatives cannot show "mass job disruption AND a good outcome". The fix is to separate two questions that a normal flowchart conflates.

    Question A: will X happen by year Y?

    One curve per event node. "Mass labour displacement by 2035: 65%." "Redistribution keeps pace by 2035: 30%." Independent propositions; any subset can be true at once. Drawn as separate lanes, never stacked.

    Question B: so how is the world doing?

    One partition of the world at each horizon into five exclusive states that sum to 100%, each with a goodness value. This is the only place a pie or a Sankey is honest, and it is where "increase a good outcome, decrease a bad one" is guaranteed by construction.

    Events affect each other through signed edges. Events affect the world-states through edges into them. Raising "alignment adequate" lowers "misaligned takeover" only because an explicit edge says so, with a strength anyone can read and argue about. The zero-sum behaviour lives only in the state renormalisation.

    Changed in v2. The world-state axis now exists at three horizons, 2030, 2035 and 2045, with the same five states each time, so the one graph has a shape over time instead of a single strip at the end. The fifth state, "stratified", is the sub-extinction bad outcome you asked about: the rich-poor divide grows without limit while GDP soars. Flows between horizons are derived by a minimal-movement rule with existential absorbing (section 4.4), so voters still only ever enter marginals.

    3. Data model

    One file, data/futures/graph.json, validated by schemas/futuresGraph.schema.json in the same ajv draft-07 style as the existing model configs. Edges are stored on the child node as a parents array, because that is where they are elicited and because it makes a later split into one file per node mechanical. Interventions live in data/futures/interventions/*.json, one file each, because that is the collection that grows.

    Rules that keep it alive for years

    • Ids never change. Retire with retired and supersededBy. Old estimates keep pointing at retired ids and stay valid history. Never migrate votes between definitions.
    • operationalisation is required for anything votable and is shown above the slider. Changing it bumps graphVersion and starts a new history segment.
    • Seeds are labelled seeds with a basis and sources, rendered with a SEED chip at the same weight as the number.
    • Versioning. schemaVersion integer with a chained migration directory. graphVersion date-based. Git is the audit trail for the locked tier.
    • Validator checks (in npm run validate): every parent resolves; event curves non-decreasing; each horizon of the axis sums to 1; any cycle must contain an edge with lag ≥ 1; edge budget 3 × nodes; note required on every edge; golden-file test on the 2045 state distribution; sensitivity report flagging any single edge worth more than 5 points on a state.

    4. Equations

    4.1 Why this form

    A true Bayesian network needs a conditional table of size 2 to the power of the parent count per node; four parents is 16 numbers nobody can elicit or maintain by vote. A scenario tree makes every branch exclusive, which is the thing we are trying not to say. Signed log-odds coupling is one number per edge, it is logistic regression, and it has a one-sentence explanation: adding +1 roughly triples the odds whether the branch started at 1% or 40%.

    4.2 Baseline curves

    logit(p) = ln(p / (1 - p))        sigmoid(x) = 1 / (1 + e^-x)
Between horizons interpolate linearly IN LOG-ODDS: L(y) = lerp(logit(P[h_k]), logit(P[h_k+1]), f),  P(y) = sigmoid(L(y))
World-states: interpolate each state the same way, then renormalise across states at every year.

    4.3 Propagation (nudges and interventions)

    u_k(y) = user or intervention shift on node k, in log-odds, zero before its start year plus lag.

for each year y in order:
  for each node j in topological order of the zero-lag edges:
    d_j(y)  = u_j(y) + clamp( sum over parents i of j:  w_ij * d_i(y - lag_ij),  -4, +4 )
    P_j'(y) = sigmoid( logit(P_j(y)) + d_j(y) )

requires edges:  P_j'(y) = min( P_j'(y), P_i'(y - lag) )     a consequence is never likelier than its prerequisite
event nodes:     P_j'(y) = max( P_j'(y), P_j'(y - 1) )        once happened, stays happened
world-states:    P_s'(y) = P_s'(y) / sum over states           exclusive, sums to 1 at every year
    • Only deltas travel. At baseline every edge contributes zero, so the curated seed is reproduced exactly and edges encode only how change propagates.
    • Feedback loops must cross a year. Any cycle contains an edge with lag ≥ 1, so each year reads frozen earlier years and there is no solver.
    • Nudges compose by addition in log-odds, so order does not matter and repeated pushes on the same lever show diminishing returns.

    4.4 The one graph: goodness over time

    Goodness values v_s: flourishing 90, muddling 60, stratified 40, catastrophe-recoverable 20, existential 0.
Mean goodness       G(y)     = sum over states s of  P_s(y) * v_s
Floor risk          F(y)     = sum over s with v_s <= 20 of P_s(y)          "catastrophe or worse"
Ceiling chance      C(y)     = sum over s with v_s >= 90 of P_s(y)          "flourishing"
Ribbon s at year y: centred at v_s, thickness proportional to P_s(y)

Flows between horizons h and h+1 (for the Sankey view only, never voted on):
  existential is absorbing: all of P_ex(h) flows to P_ex(h+1)
  the remaining mass moves by the minimal-movement coupling: sort states by goodness and
  fill the transition matrix north-west-corner style so probability moves as little as possible.
  Deterministic, no parameters, and the ribbons in the demo are its continuous form.

    4.5 Aggregating a tier

    for each voter u, latest estimate only:
  r_u = 0.5 ^ (age_days / 365)                          recency, one-year half-life
  x_u = logit( clamp(curve_u[h], 0.005, 0.995) )        never let 0 or 1 into the pool
  w_u = q_u * r_u                                       q_u = 1, editable 0.5-3 for experts by the owner
PUBLIC:  L_raw = weighted median of x_u                 robust to trolls and 0/100 spammers
EXPERT:  L_raw = weighted mean after dropping top and bottom 10% by weight
LOCKED:  L_raw = logit(seed)
n_eff   = (sum w_u)^2 / sum(w_u^2)                      Kish effective sample size
L_tier  = (n_eff * L_raw + 5 * L_locked) / (n_eff + 5)  shrink toward the seed when thin
P_tier  = sigmoid(L_tier);  band = weighted 25th and 75th percentiles, always drawn
grey out with "not enough estimates yet" when n_eff < 5.  State votes: aggregate each state, then renormalise.

    4.6 Two time axes, never overlaid

    Horizon ("by 2035") is the x-axis of the one graph and the lanes. As-of ("as of March") is when an estimate was made. Nightly snapshots give a per-node "how the expert 2035 number has moved since 2026" chart, its own small chart, with graph-version ticks. As events resolve, each tier's dated estimates get a Brier score. That is the futures map's own hindcast, and it takes years to accumulate, which is the point of starting now.

    5. Interventions, wedges and the cost curve

    The two climate charts you were thinking of are the stabilisation wedges (Pacala and Socolow 2004: a business-as-usual line, a target line, and the gap filled with stacked wedges, one per intervention, each growing from the year it starts) and the marginal abatement cost curve (bars sorted cheapest to dearest, width is how much each moves the outcome, height is cost). Both fall out of the one graph.

    Schema

    {

  "nudges": [
    { "node": "redistribution",     "direction": "up",   "magnitude": "strong",   "lag": 2, "evidence": "Sec. 3(b): 'the Fund shall distribute ... to every resident ... not less than quarterly'" },
    { "node": "oligarchic-capture", "direction": "down", "magnitude": "slight",   "lag": 3, "evidence": "Sec. 7: governance board with worker and public seats" }
  ],
  "extractedBy": { "model": "gemini-...", "asOf": "2026-09-10", "reviewedBy": null }
}
magnitude enum -> log-odds:  slight 0.25, moderate 0.5, strong 1.0   (sign from direction).  cost band 1-5.

    Four numbers per intervention, one curve

    • Mean shift. ΔG(2045). The wedge is the area between the baseline mean line and the intervened mean line.
    • Floor lift. −ΔF(2045). Your enclaves example: barely moves the mean, raises the floor. A mean-only chart calls it worthless.
    • Ceiling lift. ΔC(2045).
    • Cost. Ordinal band 1 to 5 at first. Dollars later, when someone can defend them.
    • Timing. Start year plus per-nudge lag, which shapes the wedge.

    Skew is visible directly: an intervention with five times more downside than upside shows as a ribbon thickening at the bottom while the top barely changes. Interventions compose additively in log-odds, so wedges stack and the cost curve is computed each intervention alone against baseline, which is how the climate curve does it too.

    Deliberately not modelled yet: precise costs, second-order political effects, and interventions interacting beyond additive nudges.

    6. Paste a bill

    Text or a URL goes to Gemini, which is already wired into the app. The prompt contains the node list with each node's operationalisation, the magnitude enum, and the intervention schema. The response is parsed as JSON and validated with ajv against the same schema. Three guardrails make it trustworthy:

    1. The model never sets a free number. It picks nodes from the list and magnitudes from slight / moderate / strong. Everything else is derived.
    2. Every pick carries a quoted sentence from the source as evidence, shown on the card. No quote, no nudge.
    3. Cards are "AI-drafted, unreviewed" until an editor or expert confirms them, and they live in the tier of whoever pasted them. Locked-tier interventions are git files like everything else.

    The review card is editable: change a magnitude, drop a nudge, fix a lag. Then "apply" animates the one graph from baseline to the new shape over about a second, mean line first, ribbons following. Two bills side by side on the cost curve is the comparison nobody offers today.

    Fallback when there is no API key: the card can be filled in by hand with the same form, so the feature degrades to "author an intervention".

    7. Hindcast: proving the model on the past

    This is the part Anthropic's explorer cannot do, because it starts mid-2026. The country simulator already carries per-country GDP, adoption and wellbeing. A hindcast mode initialises every country from real 2015 data, runs to 2025, and scores against actuals.

    TargetSourceCoverageScored as
    WellbeingWorld Happiness Report, Cantril ladder score per country~150 countries, yearly since 2012Correlation of predicted vs actual 2015 to 2025 change; mean absolute error in ladder points
    GDP per capitaWorld Bank WDI, constant USDAll countries, yearlySame
    UnemploymentILO modelled estimates via World BankAll countries, yearlySame, weaker weight
    AI adoptionAnthropic Economic Index, Stanford AI Index, Ramp AI IndexUS-heavy, 2023 onwardSanity band only

    One honest caveat, stated on the page. AI's macro effect on 2015 to 2025 is tiny next to COVID, war and inflation, and Korinek et al. say the same about the labour data. So the hindcast validates the baseline economy and calibrates the wellbeing coefficients. It cannot yet validate the AI displacement channel. The page should show the hindcast with AI turned off, and say "the model reproduces the last decade this well; here is what it says when AI turns on".

    Mechanics. A script fetches the three series into data/hindcast/*.json keyed by the repo's country ids. A scoring harness runs the pure engine from the 2015 snapshot and reports the metrics. Two new anchor tests: correlation of wellbeing change above 0.5, and mean absolute error below 0.6 ladder points. Both thresholds are placeholders to be set after the first run, and the first run will almost certainly fail, which is the useful information.

    9. Visuals

    • The one graph (headline). The river above, finished: ribbons with hover readouts per state per year, the mean line, ghost of the baseline mean when anything is nudged, wedges shaded between the two. A year scrubber pinned at the bottom. Mobile: the river is the landing view at any width, lanes below it.
    • Sankey view. The same data drawn discretely: three columns at 2030 / 2035 / 2045, states ordered by goodness, ribbons between columns from the minimal-movement flows. Event labels on the biggest flows explain the mechanism.
    • Lanes. One per event node, x = year, area = likelihood, grouped and collapsible, slider in the bottom sheet.
    • Interventions panel. Toggle chips, a cost-curve table, the paste-a-bill box, and the review card.
    • Influence graph. On-demand layered DAG, focused on the tapped node at depth 2, never the full hairball first.
    • Story mode. Pick an ending, walk backwards through the highest-contribution chain one screen at a time using node narratives and edge notes.
    • Tier comparison. Locked = fill, expert = solid stroke, public = dashed, always with n inline. A disagreement dot-plot sorted by spread.
    • Hindcast view. On the existing world map, a "2015 to 2025 hindcast" mode colouring countries by error, plus a scatter of predicted vs actual wellbeing change.

    Colour is reserved for valence (aqua good, orange bad, red existential, blue neutral, amber mixed), validated for colour-vision deficiency in both themes. Tiers are told apart by stroke weight and dash, never by hue.

    11. Risks

    1. False precision becomes "the site's claim". SEED chip at the same weight as the number, ranges wherever a tier has one, low-confidence curves hatched, tier selector in the header from the first frame, existential seed pinned to a citable survey median.
    2. Coupling weights rot. Edge budget 3 × nodes, max 5 parents, required note on every edge, golden-file test, sensitivity report tagging any edge worth more than 5 points as contested.
    3. Bill extraction hallucinates. Coarse enums, mandatory quotes, unreviewed badge, per-session rate limit, and locked interventions only via git.
    4. Hindcast is read as validating the AI channel. It does not. Show it with AI off, say so on the page.
    5. Public tier gets brigaded. Public never feeds locked or expert, deterministic doc ids, weighted median, App Check, n always on screen, curator freeze switch.
    6. Goodness values look arbitrary. They are. Make them editable in the manifest, show them on the y-axis, and note that the ordering matters far more than the spacing.

    13. Anthropic's Econ Scenario Explorer vs this

    Released 2026-09-09 by the Anthropic Institute's economics team: an interactive scenario explorer plus Working Paper 2026-02, Economic Scenarios for Transformative AI (Korinek, Jones, Sacher, Cotter, McCrory), plus a Morning Consult survey of 10,980 US adults.

    • A task-based macro model of the US economy, mid-2026 to 2030. Every job is a bundle of O*NET tasks. Two worker groups: cognitive occupations (62.4% of employment) and everyone else. A frictional labour market with search costs and wage rigidity is where unemployment comes from.
    • Five user-facing inputs. Capabilities, Adoption, Autonomy, Productivity, Adjustment.
    • Three scenarios, no probabilities attached, in the paper's own words.
