# data/hindcast

Observed series used to score the simulation engine against the last decade.
Generated by `npx tsx scripts/hindcast/fetch-actuals.ts` - do not edit by hand.
Refetch with `--force`.

Every file has the shape:

```json
{ "series": "...", "units": "...", "source": { "url": "...", "retrievedAt": "YYYY-MM-DD" },
  "data": { "USA": { "2015": 6.86, "2016": 6.8 }, "...": {} } }
```

Keys are ISO3 country codes, matching the `id` field of `INITIAL_COUNTRIES` in `constants.ts`.
World Bank aggregates (WLD, EUU, ...) and OWID regions are filtered out at fetch time.

| File | Series | Units | Countries | Rows | Years | Retrieved |
|---|---|---|---|---|---|---|
| `wellbeing-ladder.json` | wellbeing-ladder | Cantril ladder, 0 (worst possible life) to 10 (best possible life) | 164 | 2089 | 2011-2025 | 2026-09-10 |
| `gdp-per-capita.json` | gdp-per-capita | constant 2015 US$ per person per year | 213 | 3308 | 2010-2025 | 2026-09-10 |
| `unemployment.json` | unemployment | percent of total labour force | 187 | 2978 | 2010-2025 | 2026-09-10 |

## Sources

- **wellbeing-ladder.json** - World Happiness Report / Gallup World Poll, via Our World in Data
  - URL: https://ourworldindata.org/grapher/happiness-cantril-ladder.csv
  - Fallback (manual, xlsx): https://worldhappiness.report/data-sharing/
  - Retrieved: 2026-09-10
- **gdp-per-capita.json** - World Bank World Development Indicators (NY.GDP.PCAP.KD)
  - URL: https://api.worldbank.org/v2/country/all/indicator/NY.GDP.PCAP.KD?format=json&per_page=20000&date=2010:2025
  - Source last updated: 2026-07-13
  - Retrieved: 2026-09-10
- **unemployment.json** - World Bank World Development Indicators (SL.UEM.TOTL.ZS)
  - URL: https://api.worldbank.org/v2/country/all/indicator/SL.UEM.TOTL.ZS?format=json&per_page=20000&date=2010:2025
  - Source last updated: 2026-07-13
  - Retrieved: 2026-09-10

## Notes

- The Cantril ladder is 0-10. The harness scales it to the simulator's 0-100 wellbeing
  index by multiplying by 10 (`ladderToWellbeingIndex` in `validation/hindcast.ts`).
- GDP per capita is in **constant 2015 US$** (`NY.GDP.PCAP.KD`), so 2015 levels are directly
  comparable with the `gdpPerCapita` field in `constants.ts` (which is nominal, circa 2020).
- Unemployment is the ILO modelled estimate (`SL.UEM.TOTL.ZS`). It is fetched for completeness;
  the current engine has no unemployment state variable, so nothing scores against it yet.
